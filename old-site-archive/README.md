## What this archive does NOT contain

This is a **URL inventory only**. It does not contain post content, media
files, ACF/post meta, or theme settings.

Before deleting the site you still need a real WordPress export:

1. WP Admin → Tools → Export → "All content" → Download Export File (.xml)
2. Hostinger → Files → File Manager → download `wp-content/uploads/` (all images)

The WXR export includes post bodies, custom post types, taxonomies and meta
that the REST API does not reliably expose. Keep both alongside this folder.
